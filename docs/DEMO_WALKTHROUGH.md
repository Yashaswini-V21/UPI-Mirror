# UPI Mirror Demo Walkthrough

Use this script for a 5-7 minute product demo.

## 1. Opening (30s)
- State the problem: most tools show spending history, but not behavioral risk.
- Introduce UPI Mirror as a behavioral finance coach built on UPI transaction data.

## 2. DS Features Tab (2m)
- Show Month-to-date, Broke Date, and Top Habit Alert cards.
- Walk through daily spend chart and weekly anomaly chart.
- Explain addiction score and what score movement means.

## 3. Regret + Merchant Tabs (1.5m)
- Show high-regret categories and time-of-day patterns.
- Highlight late-night merchant concentration and why it matters.

## 4. Coach Agent Tab (2m)
- Explain status (stable/watch/critical).
- Show narrative, nudge, and suggested cap.
- Capture feedback (I'll try it / Not for me) and explain reward signal.
- Capture Agent Lightning trace and point out reward source.

## 5. Delivery + Sharing (1m)
- Open WhatsApp/email draft from the coach nudge.
- Show LinkedIn insight card and CSV export.

## 6. Closing (30s)
- Summarize: prediction + behavior diagnosis + intervention + traceable feedback loop.
- Mention all modules run locally with optional AI integrations.
